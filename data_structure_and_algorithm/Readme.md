# 数据结构与算法分析

本节包含《数据结构与算法分析：C语言描述（原书第二版）》电子书、学习笔记以及代码实现

- ISBN：7-111-12748-X
- 电子书：托管在github pages，这里贴一个链接

数据结构主要研究组织大量数据的方法；算法分析则是对算法运行时间的评估。
