# 排序算法

> 本节内容默认按照升序排列

- 冒泡排序 bubble sort
    - 算法：不断比较相邻两个值，`a>b`则交换，循环这个过程
    - 稳定性：稳定（注意交换条件为`a>b`，相等也交换就不稳定了，稳定算法基本都需要注意边界条件）
- 选择排序 selection sort
    - 算法：选出剩余元素中的最小值，交换到有序部分的末尾，循环这个过程
    - 稳定性：不稳定
- 插入排序 insertion sort
    - 算法：选择有序部分的下一个元素，将它插入有序部分中它应该在的位置，循环这个过程
    - 稳定性：稳定（新元素`a`应插入`b1<=a<b2`位置）
- 归并排序 merge sort
    - 算法：将集合分成数量基本相等的两部分，如果每一部分都是有序的，则将它们有序合并到新的数组；如果任一部分不是有序的，则继续分
        - 有序的一部分：仅包含1个元素的集合或排序后的集合
    - 稳定性：稳定（两个部分的元素相等时，应取左侧的元素）
- 快速排序 quick sort
    - 算法：选择一个基准元素，将比它小的元素都放在它的左边、比它大的元素都放在它的右边，在基准元素左右分别循环这个过程
    - 稳定性：不稳定
- 基数排序 base sort
    - 算法：对每个元素，从低位到高位依次使用计数排序，然后按照顺序放回去，重复这个过程，直到位数最多的元素也完成排序
    - 稳定性：稳定（非比较排序，通常总是稳定的）
    - 计数排序：利用索引统计每个值的出现次数，适合集合元素上下界之间可以枚举的场景（枚举数量较少）
- 堆排序 heap sort
    - 算法：根据堆的性质，构造一个堆然后不断的从中取出数据
    - 稳定性：不稳定

注：

- 计数排序适用范围特殊，仅作为基数排序的一部分，不单独展开
- 桶排序是计数排序的一种扩展（计数排序对单个元素计数，桶排序则是对一个范围计数），也不展开
- 比较排序：一直到快速排序，前5种排序算法属于比较排序，它们会在集合的元素之间进行比较；
  后面2种排序算法则是比较元素的一部分或者在排序过程中不进行比较，属于非比较排序

## 排序算法的稳定性

定义：相等的元素在排序前的相对位置与排序后的相对位置是否保持不变

- 相等的元素：指根据本次排序条件，比较结果相等的一组元素

稳定的排序算法可以保留原本序列中的顺序性，一些场景会限制只能使用稳定的排序算法。举个例子，假设有一组商品，
它们已经按照价格升序排列，现在希望你将它们保持价格顺序的同时，按照销量降序排列。这时候就需要使用稳定的排序算法了。
